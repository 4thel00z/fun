---
title: Node-API
description: Use Fun's Node-API module to build native add-ons to Node.js
---

Node-API is an interface for building native add-ons to Node.js. Fun implements 95% of this interface from scratch, so most existing Node-API extensions will work with Fun out of the box. Track the completion status of it in [this issue](https://github.com/underdoc-org/fun/issues/158).

As in Node.js, `.node` files (Node-API modules) can be required directly in Fun.

```js
const napi = require("./my-node-module.node");
```

Alternatively, use `process.dlopen`:

```js
let mod = { exports: {} };
process.dlopen(mod, "./my-node-module.node");
```
