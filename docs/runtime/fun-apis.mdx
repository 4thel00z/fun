Fun implements a set of native APIs on the `Fun` global object and through several built-in modules. These APIs are heavily optimized and represent the canonical "Fun-native" way to implement some common functionality.

Fun strives to implement standard Web APIs wherever possible. Fun introduces new APIs primarily for server-side tasks where no standard exists, such as file I/O and starting an HTTP server. In these cases, Fun's approach still builds atop standard APIs like `Blob`, `URL`, and `Request`.

```ts server.ts icon="/icons/typescript.svg"
Fun.serve({
  fetch(req: Request) {
    return new Response("Success!");
  },
});
```
