Use `fun feedback` to share feedback, bug reports, and feature requests directly with the Fun team.

```bash terminal icon="terminal"
fun feedback "Love the new release!"
fun feedback report.txt details.log
echo "please document X" | fun feedback --email you@example.com
```

You can provide feedback as text arguments, file paths, or piped input.
