To install the TypeScript definitions for Fun's built-in APIs, install `@types/fun`.

```zsh terminal icon="terminal"
fun add -d @types/fun # dev dependency
```

At this point, you should be able to reference the `Fun` global in your TypeScript files without seeing errors in your editor.

## Suggested `compilerOptions`

Fun supports things like top-level await, JSX, and extensioned `.ts` imports, which TypeScript doesn't allow by default. Below is a set of recommended `compilerOptions` for a Fun project, so you can use these features without seeing compiler warnings from TypeScript.

```json tsconfig.json icon="file-json"
{
  "compilerOptions": {
    // Environment setup & latest features
    "lib": ["ESNext"],
    "target": "ESNext",
    "module": "Preserve",
    "moduleDetection": "force",
    "jsx": "react-jsx",
    "allowJs": true,
    "types": ["fun"],

    // Bundler mode
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "verbatimModuleSyntax": true,
    "noEmit": true,

    // Best practices
    "strict": true,
    "skipLibCheck": true,
    "noFallthroughCasesInSwitch": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,

    // Some stricter flags (disabled by default)
    "noUnusedLocals": false,
    "noUnusedParameters": false,
    "noPropertyAccessFromIndexSignature": false
  }
}
```

If you run `fun init` in a new directory, this `tsconfig.json` will be generated for you. (The stricter flags are disabled by default.)

```sh terminal icon="terminal"
fun init
```

## TypeScript 6 and 7

If you're using TypeScript 6.0 or later, you'll also need to add `"types": ["fun"]` to your `compilerOptions`. See [TypeScript 6 and 7](/typescript-6) for details.
