<Note>`funx` is an alias for `fun x`. The `funx` CLI will be auto-installed when you install `fun`.</Note>

Use `funx` to auto-install and run packages from `npm`. It's Fun's equivalent of `npx` or `yarn dlx`.

```bash terminal icon="terminal"
funx cowsay "Hello world!"
```

<Note>
  ⚡️ **Speed** — With Fun's fast startup times, `funx` is [roughly 100x
  faster](https://twitter.com/jarredsumner/status/1606163655527059458) than `npx` for locally installed packages.
</Note>

Packages can declare executables in the `"bin"` field of their `package.json`. These are known as _package executables_ or _package binaries_.

```json package.json icon="file-json"
{
  // ... other fields
  "name": "my-cli",
  "bin": {
    "my-cli": "dist/index.js"
  }
}
```

These executables are commonly plain JavaScript files marked with a [shebang line](<https://en.wikipedia.org/wiki/Shebang_(Unix)>) to indicate which program should be used to execute them. The following file indicates that it should be executed with `node`.

```js dist/index.js icon="/icons/javascript.svg"
#!/usr/bin/env node

console.log("Hello world!");
```

These executables can be run with `funx`,

```bash terminal icon="terminal"
funx my-cli
```

As with `npx`, `funx` will check for a locally installed package first, then fall back to auto-installing the package from `npm`. Installed packages will be stored in Fun's global cache for future use.

## Arguments and flags

To pass additional command-line flags and arguments through to the executable, place them after the executable name.

```bash terminal icon="terminal"
funx my-cli --foo bar
```

---

## Shebangs

By default, Fun respects shebangs. If an executable is marked with `#!/usr/bin/env node`, Fun will spin up a `node` process to execute the file. However, in some cases it may be desirable to run executables using Fun's runtime, even if the executable indicates otherwise. To do so, include the `--fun` flag.

```bash terminal icon="terminal"
funx --fun my-cli
```

The `--fun` flag must occur _before_ the executable name. Flags that appear _after_ the name are passed through to the executable.

```bash terminal icon="terminal"
funx --fun my-cli # good
funx my-cli --fun # bad
```

## Package flag

**`--package <pkg>` or `-p <pkg>`** - Run binary from specific package. Useful when binary name differs from package name:

```bash terminal icon="terminal"
funx -p renovate renovate-config-validator
funx --package @angular/cli ng
```

To force fun to always be used with a script, use a shebang.

```js dist/index.js icon="/icons/javascript.svg"
#!/usr/bin/env fun
```
