---
title: "fun info"
description: "Display package metadata from the npm registry"
---

`fun info` displays package metadata from the npm registry.

## Usage

```bash terminal icon="terminal"
fun info react
```

This will display information about the `react` package, including its latest version, description, homepage, dependencies, and more.

## Viewing specific versions

To view information about a specific version:

```bash terminal icon="terminal"
fun info react@18.0.0
```

## Viewing specific properties

You can also query specific properties from the package metadata:

```bash terminal icon="terminal"
fun info react version
fun info react dependencies
fun info react repository.url
```

## JSON output

To get the output in JSON format, use the `--json` flag:

```bash terminal icon="terminal"
fun info react --json
```

## Alias

`fun pm view` is an alias for `fun info`:

```bash terminal icon="terminal"
fun pm view react  # equivalent to: fun info react
```

## Examples

```bash terminal icon="terminal"
# View basic package information
fun info is-number

# View a specific version
fun info is-number@7.0.0

# View all available versions
fun info is-number versions

# View package dependencies
fun info express dependencies

# View package homepage
fun info lodash homepage

# Get JSON output
fun info react --json
```
