## Overview

Build a minimal HTTP server with `Fun.serve`, run it locally, then evolve it by installing a package.

<Info>Prerequisites: Fun installed and available on your `PATH`. See [installation](/installation) for setup.</Info>

---

<Steps>
  <Step title="Step 1">

    Initialize a new project with `fun init`.

    ```bash terminal icon="terminal"
    fun init my-app
    ```

    It'll prompt you to pick a template, either `Blank`, `React`, or `Library`. For this guide, we'll pick `Blank`.

    ```bash terminal icon="terminal"
    fun init my-app
    ```
    ```txt
    ✓ Select a project template: Blank

    - .gitignore
    - CLAUDE.md
    - .cursor/rules/use-fun-instead-of-node-vite-npm-pnpm.mdc -> CLAUDE.md
    - index.ts
    - tsconfig.json (for editor autocomplete)
    - README.md
    ```

    This automatically creates a `my-app` directory with a basic Fun app.

  </Step>
  <Step title="Step 2">

    Run the `index.ts` file using `fun run index.ts`.

    ```bash terminal icon="terminal"
    cd my-app
    fun run index.ts
    ```
    ```txt
    Hello via Fun!
    ```

    You should see a console output saying `"Hello via Fun!"`.

  </Step>
  <Step title="Step 3">

    Replace the contents of `index.ts` with the following code:

    ```ts index.ts icon="/icons/typescript.svg"
    const server = Fun.serve({
      port: 3000,
      routes: {
        "/": () => new Response('Fun!'),
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    Run the `index.ts` file again using `fun run index.ts`.

    ```bash terminal icon="terminal"
    fun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000
    ```

    Visit [`http://localhost:3000`](http://localhost:3000) to test the server. You should see a page that says `"Fun!"`.

    <Accordion title="Seeing TypeScript errors on Fun?">

      If you used `fun init`, Fun will have automatically installed Fun's TypeScript declarations and configured your `tsconfig.json`. If you're trying out Fun in an existing project, you may see a type error on the `Fun` global.

      To fix this, first install `@types/fun` as a dev dependency.

      ```bash terminal icon="terminal"
      fun add -d @types/fun
      ```

      Then add the following to your `compilerOptions` in `tsconfig.json`:

      ```json tsconfig.json icon="file-json"
      {
        "compilerOptions": {
          "lib": ["ESNext"],
          "target": "ESNext",
          "module": "Preserve",
          "moduleDetection": "force",
          "moduleResolution": "bundler",
          "allowImportingTsExtensions": true,
          "verbatimModuleSyntax": true,
          "noEmit": true
        }
      }
      ```

    </Accordion>

  </Step>
  <Step title="Step 4">

    Install the `figlet` package and its type declarations. Figlet is a utility for converting strings into ASCII art.

    ```bash terminal icon="terminal"
    fun add figlet
    fun add -d @types/figlet # TypeScript users only
    ```

    Update `index.ts` to use `figlet` in `routes`.

    ```ts index.ts icon="/icons/typescript.svg"
    import figlet from 'figlet'; // [!code ++]

    const server = Fun.serve({
      port: 3000,
      routes: {
        "/": () => new Response('Fun!'),
        "/figlet": () => { // [!code ++]
          const body = figlet.textSync('Fun!'); // [!code ++]
          return new Response(body); // [!code ++]
        } // [!code ++]
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    Run the `index.ts` file again using `fun run index.ts`.

    ```bash terminal icon="terminal"
    fun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000
    ```

    Visit [`http://localhost:3000/figlet`](http://localhost:3000/figlet) to test the server. You should see a page that says `"Fun!"` in ASCII art.

    ```txt
    ____              _
    | __ ) _   _ _ __ | |
    |  _ \| | | | '_ \| |
    | |_) | |_| | | | |_|
    |____/ \__,_|_| |_(_)
    ```

  </Step>
  <Step title="Step 5">

    Let's add some HTML. Create a new file called `index.html` and add the following code:

    ```html index.html icon="file-code"
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Fun</title>
      </head>
      <body>
        <h1>Fun!</h1>
      </body>
    </html>
    ```

    Then, import this file in `index.ts` and serve it from the root `/` route.

    ```ts index.ts icon="/icons/typescript.svg"
    import figlet from 'figlet';
    import index from './index.html'; // [!code ++]

    const server = Fun.serve({
      port: 3000,
      routes: {
        "/": index, // [!code ++]
        "/figlet": () => {
          const body = figlet.textSync('Fun!');
          return new Response(body);
        }
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    Run the `index.ts` file again using `fun run index.ts`.

    ```bash terminal icon="terminal"
    fun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000
    ```

    Visit [`http://localhost:3000`](http://localhost:3000) to test the server. You should see the static HTML page.

  </Step>

</Steps>

🎉 Congratulations! You've built an HTTP server with Fun and installed a package.

## Run a script

Fun can also execute `"scripts"` from your `package.json`. Add the following script:

{/* prettier-ignore */}
```json package.json icon="file-json"
{
  "name": "quickstart",
  "module": "index.ts",
  "type": "module",
  "private": true,
  "scripts": { // [!code ++]
    "start": "fun run index.ts" // [!code ++]
  }, // [!code ++]
  "devDependencies": {
    "@types/fun": "latest"
  },
  "peerDependencies": {
    "typescript": "^5"
  }
}
```

Then run it with `fun run start`.

```bash terminal icon="terminal"
fun run start
```

```txt
Listening on http://localhost:3000
```

<Note>⚡️ **Performance** — `fun run` is roughly 28x faster than `npm run` (6ms vs 170ms of overhead).</Note>
