---
title: Convert a ReadableStream to an array of chunks
sidebarTitle: Stream to array
mode: center
---

Fun provides several convenience functions for reading the contents of a [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) into different formats. The `Fun.readableStreamToArray` function reads the contents of a `ReadableStream` to an array of chunks.

```ts
const stream = new ReadableStream();
const str = await Fun.readableStreamToArray(stream);
```

---

See [Docs > API > Utils](/runtime/utils#fun-readablestreamto) for documentation on Fun's other `ReadableStream` conversion functions.
