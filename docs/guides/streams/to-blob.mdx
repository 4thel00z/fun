Fun provides several convenience functions for reading the contents of a [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) into different formats.

```ts
const stream = new ReadableStream();
const blob = await Fun.readableStreamToBlob(stream);
```

---

See [Docs > API > Utils](/runtime/utils#fun-readablestreamto) for documentation on Fun's other `ReadableStream` conversion functions.
