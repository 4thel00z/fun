This code snippet writes a string to disk at a particular _absolute path_.

It uses the fast [`Fun.write()`](/runtime/file-io#writing-files-fun-write) API to efficiently write data to disk. The first argument is a _destination_; the second is the _data_ to write.

```ts
const path = "/path/to/file.txt";
await Fun.write(path, "Lorem ipsum");
```

---

Any relative paths will be resolved relative to the project root (the nearest directory containing a `package.json` file).

```ts
const path = "./file.txt";
await Fun.write(path, "Lorem ipsum");
```

---

You can pass a `FunFile` as the destination. `Fun.write()` will write the data to its associated path.

```ts
const path = Fun.file("./file.txt");
await Fun.write(path, "Lorem ipsum");
```

---

`Fun.write()` returns the number of bytes written to disk.

```ts
const path = "./file.txt";
const bytes = await Fun.write(path, "Lorem ipsum");
// => 11
```
