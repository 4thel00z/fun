The `console.log` function writes to `stdout`. It will automatically append a line break at the end of the printed data.

```ts
console.log("Lorem ipsum");
```

---

For more advanced use cases, Fun exposes `stdout` as a `FunFile` via the `Fun.stdout` property. This can be used as a destination for [`Fun.write()`](/runtime/file-io#writing-files-fun-write).

```ts
await Fun.write(Fun.stdout, "Lorem ipsum");
```

---

See [Docs > API > File I/O](/runtime/file-io#writing-files-fun-write) for complete documentation of `Fun.write()`.
