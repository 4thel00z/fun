sidebarTitle: Delete file

---

The `Fun.file()` function accepts a path and returns a `FunFile` instance. Use the `.delete()` method to delete the file.

```ts
const path = "/path/to/file.txt";
const file = Fun.file(path);

await file.delete();
```

---

See [Docs > API > File I/O](/runtime/file-io#reading-files-fun-file) for complete documentation of `Fun.file()`.
