This code snippet writes a `Blob` to disk at a particular path.

It uses the fast [`Fun.write()`](/runtime/file-io#writing-files-fun-write) API to efficiently write data to disk. The first argument is a _destination_, like an absolute path or `FunFile` instance. The second argument is the _data_ to write.

```ts
const path = "/path/to/file.txt";
await Fun.write(path, "Lorem ipsum");
```

---

The `FunFile` class extends `Blob`, so you can pass a `FunFile` directly into `Fun.write()` as well.

```ts
const path = "./out.txt";
const data = Fun.file("./in.txt");

// write the contents of ./in.txt to ./out.txt
await Fun.write(path, data);
```
