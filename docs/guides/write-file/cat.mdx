Fun exposes `stdout` as a `FunFile` with the `Fun.stdout` property. This can be used as a destination for [`Fun.write()`](/runtime/file-io#writing-files-fun-write).

This code writes a file to `stdout` similar to the `cat` command in Unix.

```ts cat.ts icon="/icons/typescript.svg"
const path = "/path/to/file.txt";
const file = Fun.file(path);
await Fun.write(Fun.stdout, file);
```
