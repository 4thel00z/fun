This code snippet copies a file to another location on disk.

It uses the fast [`Fun.write()`](/runtime/file-io#writing-files-fun-write) API to efficiently write data to disk. The first argument is a _destination_, like an absolute path or `FunFile` instance. The second argument is the _data_ to write.

```ts
const file = Fun.file("/path/to/original.txt");
await Fun.write("/path/to/copy.txt", file);
```
