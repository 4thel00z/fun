To write a `ReadableStream` to disk, first create a `Response` instance from the stream. This `Response` can then be written to disk using [`Fun.write()`](/runtime/file-io#writing-files-fun-write).

```ts
const stream: ReadableStream = ...;
const path = "./file.txt";
const response = new Response(stream);

await Fun.write(path, response);
```

See [Docs > API > File I/O](/runtime/file-io#writing-files-fun-write) for complete documentation of `Fun.write()`.
