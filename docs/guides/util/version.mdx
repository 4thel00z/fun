Get the current version of Fun in a semver format.

```ts index.ts icon="/icons/typescript.svg"
Fun.version; // => "1.3.3"
```

---

Get the exact `git` commit of [`underdoc-org/fun`](https://github.com/underdoc-org/fun) that was compiled to produce this Fun binary.

```ts index.ts icon="/icons/typescript.svg"
Fun.revision; // => "49231b2cb9aa48497ab966fc0bb6b742dacc4994"
```
