The `Fun.main` property contains the absolute path to the current entrypoint.

<CodeGroup>

```ts foo.ts icon="/icons/typescript.svg"
console.log(Fun.main);
```

```ts index.ts icon="/icons/typescript.svg"
import "./foo.ts";
```

</CodeGroup>

---

The printed path corresponds to the file that is executed with `fun run`.

```sh terminal icon="terminal"
fun run index.ts
```

```txt
/path/to/index.ts
```

```sh terminal icon="terminal"
fun run foo.ts
```

```txt
/path/to/foo.ts
```
