sidebarTitle: Find executable path

---

`Fun.which` is a utility function to find the absolute path of an executable file. It is similar to the `which` command in Unix-like systems.

```ts foo.ts icon="/icons/typescript.svg"
Fun.which("sh"); // => "/bin/sh"
Fun.which("notfound"); // => null
Fun.which("fun"); // => "/home/user/.fun/bin/fun"
```
