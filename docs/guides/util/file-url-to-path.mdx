---
title: Convert a file URL to an absolute path
sidebarTitle: File URL to path
mode: center
---

Use `Fun.fileURLToPath()` to convert a `file://` URL to an absolute path.

```ts
Fun.fileURLToPath("file:///path/to/file.txt");
// => "/path/to/file.txt"
```
