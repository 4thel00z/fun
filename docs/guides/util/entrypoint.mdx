title: Check if the current file is the entrypoint
sidebarTitle: Check entrypoint

---

Fun provides a handful of module-specific utilities on the [`import.meta`](/runtime/module-resolution#import-meta) object. Use `import.meta.main` to check if the current file is the entrypoint of the current process.

```ts index.ts icon="/icons/typescript.svg"
if (import.meta.main) {
  // this file is directly executed with `fun run`
} else {
  // this file is being imported by another file
}
```

See [Docs > API > import.meta](/runtime/module-resolution#import-meta) for complete documentation.
