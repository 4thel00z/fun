---
title: Get the MIME type of a file
sidebarTitle: Get MIME type
mode: center
---

The `Fun.file()` function accepts a path and returns a `FunFile` instance. The `FunFile` class extends `Blob`, so use the `.type` property to read the MIME type.

```ts
const file = Fun.file("./package.json");
file.type; // application/json

const file = Fun.file("./index.html");
file.type; // text/html

const file = Fun.file("./image.png");
file.type; // image/png
```

---

Refer to [API > File I/O](/runtime/file-io) for more information on working with `FunFile`.
