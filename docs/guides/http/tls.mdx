---
title: Configure TLS on an HTTP server
sidebarTitle: Configure TLS
mode: center
---

Set the `tls` key to configure TLS. Both `key` and `cert` are required. The `key` should be the contents of your private key; `cert` should be the contents of your issued certificate. Use [`Fun.file()`](/runtime/file-io#reading-files-fun-file) to read the contents.

```ts server.ts icon="/icons/typescript.svg"
const server = Fun.serve({
  fetch: request => new Response("Welcome to Fun!"),
  tls: {
    cert: Fun.file("cert.pem"),
    key: Fun.file("key.pem"),
  },
});
```

---

By default Fun trusts the default Mozilla-curated list of well-known root CAs. To override this list, pass an array of certificates as `ca`.

```ts server.ts icon="/icons/typescript.svg"
const server = Fun.serve({
  fetch: request => new Response("Welcome to Fun!"),
  tls: {
    cert: Fun.file("cert.pem"),
    key: Fun.file("key.pem"),
    ca: [Fun.file("ca1.pem"), Fun.file("ca2.pem")],
  },
});
```
