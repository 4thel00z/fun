Fun implements the Web-standard [`fetch`](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) API for sending HTTP requests. To send a simple `GET` request to a URL:

```ts fetch.ts icon="/icons/typescript.svg"
const response = await fetch("https://fun.dev");
const html = await response.text(); // HTML string
```

---

To send a `POST` request to an API endpoint.

```ts fetch.ts icon="/icons/typescript.svg"
const response = await fetch("https://fun.dev/api", {
  method: "POST",
  body: JSON.stringify({ message: "Hello from Fun!" }),
  headers: { "Content-Type": "application/json" },
});

const body = await response.json();
```
