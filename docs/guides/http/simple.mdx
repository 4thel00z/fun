This starts an HTTP server listening on port `3000`. It responds to all requests with a `Response` with status `200` and body `"Welcome to Fun!"`.

See [`Fun.serve`](/runtime/http/server) for details.

```ts server.ts icon="/icons/typescript.svg"
const server = Fun.serve({
  port: 3000,
  fetch(request) {
    return new Response("Welcome to Fun!");
  },
});

console.log(`Listening on ${server.url}`);
```
