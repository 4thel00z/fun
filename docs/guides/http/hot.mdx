Fun supports the [`--hot`](/runtime/watch-mode#hot-mode) flag to run a file with hot reloading enabled. When any module or file changes, Fun re-runs the file.

```sh terminal icon="terminal"
fun --hot run index.ts
```

---

Fun detects when you are running an HTTP server with `Fun.serve()`. It reloads your fetch handler when source files change, _without_ restarting the `fun` process. This makes hot reloads nearly instantaneous.

<Note>
Note that this doesn't reload the page on your browser.
</Note>
 
```ts index.ts icon="/icons/typescript.svg"
Fun.serve({
  port: 3000,
  fetch(req) {
    return new Response("Hello world");
  },
});
```
