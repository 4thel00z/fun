Initialize a fresh Astro app with `fun create astro`. The `create-astro` package detects when you are using `funx` and will automatically install dependencies using `fun`.

```sh terminal icon="terminal"
fun create astro
```

---

Start the dev server with `funx`.

By default, Fun will run the dev server with Node.js. To use the Fun runtime instead, use the `--fun` flag.

```sh terminal icon="terminal"
funx --fun astro dev
```

```txt
  🚀  astro  v3.1.4 started in 200ms

  ┃ Local    http://localhost:4321/
  ┃ Network  use --host to expose
```

---

Open [http://localhost:4321](http://localhost:4321) with your browser to see the result. Astro will hot-reload your app as you edit your source files.
