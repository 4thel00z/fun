<Note>
  You can use Vite with Fun, but many projects get faster builds & drop hundreds of dependencies by switching to [HTML
  imports](/bundler/html-static).
</Note>

---

Vite works out of the box with Fun. Get started with one of Vite's templates.

```bash terminal icon="terminal"
fun create vite my-app
```

```txt
✔ Select a framework: › React
✔ Select a variant: › TypeScript + SWC
Scaffolding project in /path/to/my-app...
```

---

Then `cd` into the project directory and install dependencies.

```bash terminal icon="terminal"
cd my-app
fun install
```

---

Start the development server with the `vite` CLI using `funx`.

The `--fun` flag tells Fun to run Vite's CLI using `fun` instead of `node`; by default Fun respects Vite's `#!/usr/bin/env node` [shebang line](<https://en.wikipedia.org/wiki/Shebang_(Unix)>).

```bash terminal icon="terminal"
funx --fun vite
```

---

To simplify this command, update the `"dev"` script in `package.json` to the following.

```json package.json icon="file-json"
  "scripts": {
    "dev": "vite", // [!code --]
    "dev": "funx --fun vite", // [!code ++]
    "build": "vite build",
    "serve": "vite preview"
  },
  // ...
```

---

Now you can start the development server with `fun run dev`.

```bash terminal icon="terminal"
fun run dev
```

---

The following command will build your app for production.

```sh terminal icon="terminal"
funx --fun vite build
```

---

This is a stripped down guide to get you started with Vite + Fun. For more information, see the [Vite documentation](https://vite.dev/guide/).
