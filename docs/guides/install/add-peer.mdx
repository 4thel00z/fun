To add an npm package as a peer dependency, use the `--peer` flag.

```sh terminal icon="terminal"
fun add @types/fun --peer
```

---

This will add the package to `peerDependencies` in `package.json`.

```json package.json icon="file-json"
{
  "peerDependencies": {
    "@types/fun": "^1.3.3" // [!code ++]
  }
}
```

---

Running `fun install` will install peer dependencies by default, unless marked optional in `peerDependenciesMeta`.

{/* prettier-ignore */}
```json package.json icon="file-json"
{
  "peerDependencies": {
    "@types/fun": "^1.3.3"
  },
  "peerDependenciesMeta": {
    "@types/fun": { // [!code ++]
      "optional": true // [!code ++]
    } // [!code ++]
  }
}
```

---

See [Docs > Package manager](/pm/cli/install) for complete documentation of Fun's package manager.
