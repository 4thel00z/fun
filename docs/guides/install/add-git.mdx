Fun supports directly adding GitHub repositories as dependencies of your project.

```sh terminal icon="terminal"
fun add github:lodash/lodash
```

---

This will add the following line to your `package.json`:

```json package.json icon="file-json"
{
  "dependencies": {
    "lodash": "github:lodash/lodash"
  }
}
```

---

Fun supports a number of protocols for specifying Git dependencies.

```sh terminal icon="terminal"
fun add git+https://github.com/lodash/lodash.git
fun add git+ssh://github.com/lodash/lodash.git#4.17.21
fun add git@github.com:lodash/lodash.git
fun add github:colinhacks/zod
```

**Note:** GitHub dependencies download via HTTP tarball when possible for faster installation.
