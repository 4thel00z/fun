To add an npm package as a development dependency, use `fun add --development`.

```sh terminal icon="terminal"
fun add zod --dev
fun add zod -d # shorthand
```

---

This will add the package to `devDependencies` in `package.json`.

```json
{
  "devDependencies": {
    "zod": "^3.0.0" // [!code ++]
  }
}
```

---

See [Docs > Package manager](/pm/cli/install) for complete documentation of Fun's package manager.
