title: Configure a private registry for an organization scope with fun install

Private registries can be configured using either [`.npmrc`](/pm/npmrc) or [`funfig.toml`](/runtime/funfig#install-registry). While both are supported, we recommend using **funfig.toml** for enhanced flexibility and Fun-specific options.

To configure a registry for a particular npm scope:

```toml funfig.toml icon="settings"
[install.scopes]
# as a string
"@myorg1" = "https://usertitle:password@registry.myorg.com/"

# as an object with username/password
# you can reference environment variables
"@myorg2" = {
  username = "myusername",
  password = "$npm_pass",
  url = "https://registry.myorg.com/"
}

# as an object with token
"@myorg3" = { token = "$npm_token", url = "https://registry.myorg.com/" }

```

---

Your `funfig.toml` can reference environment variables. Fun automatically loads environment variables from `.env.local`, `.env.[NODE_ENV]`, and `.env`. See [Docs > Environment variables](/runtime/environment-variables) for more information.

```toml funfig.toml icon="settings"
[install.scopes]
"@myorg3" = { token = "$npm_token", url = "https://registry.myorg.com/" }
```
