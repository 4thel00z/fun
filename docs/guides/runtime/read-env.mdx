The current environment variables can be accessed via `process.env`.

```ts index.ts icon="/icons/typescript.svg"
process.env.API_TOKEN; // => "secret"
```

---

Fun also exposes these variables via `Fun.env`, which is an alias of `process.env`.

```ts index.ts icon="/icons/typescript.svg"
Fun.env.API_TOKEN; // => "secret"
```

---

To print all currently-set environment variables to the command line, run `fun --print process.env`. This is useful for debugging.

```sh terminal icon="terminal"
fun --print process.env
```

```txt
BAZ=stuff
FOOBAR=aaaaaa
<lots more lines>
```
