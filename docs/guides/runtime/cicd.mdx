---
title: Install and run Fun in GitHub Actions
sidebarTitle: GitHub Actions
mode: center
---

Use the official [`setup-fun`](https://github.com/oven-sh/setup-fun) GitHub Action to install `fun` in your GitHub Actions runner.

```yaml workflow.yml icon="file-code"
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-fun@v2 # [!code ++]

      # run any `fun` or `funx` command
      - run: fun install # [!code ++]
      - run: fun index.ts # [!code ++]
      - run: fun run build # [!code ++]
```

---

To specify a version of Fun to install:

```yaml workflow.yml icon="file-code"
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: oven-sh/setup-fun@v2
        with: # [!code ++]
          fun-version: 1.3.3 # or "latest", "canary", <sha> # [!code ++]
```

---

Refer to the [README.md](https://github.com/oven-sh/setup-fun) for complete documentation of the `setup-fun` GitHub Action.
