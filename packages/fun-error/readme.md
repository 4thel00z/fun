# fun-error

<img width="687" alt="image" src="https://user-images.githubusercontent.com/709451/162382958-23614e8f-239c-4ba6-be75-b76ceef8227c.png">

`fun-error` is a frontend component for rendering error messages and stack traces from Fun. It's used in:

- `fun dev`
- `Fun.serve`

It is heavily tied to the implementation details of Fun, and is not intended to be used outside of Fun.
